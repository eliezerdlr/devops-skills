# Map and query a trusted project

**Local adaptation for DevOps Skills.** Graphify-derived instructions are Apache-2.0; see [NOTICE](../NOTICE).

1. Confirm project root, branch/worktree, question and authorised corpus. If the request is only a question, prefer an existing map or direct selective reads.
2. Load [the skill](../skills/graphify/SKILL.md), then only the relevant reference.
3. Confirm the external CLI is the reviewed version; if unavailable, report the limitation without installing it.
4. If no map exists or it is stale, ask before writing outputs. Follow [incremental update](../skills/graphify/references/incremental-update.md), including local-only process settings and output checks.
5. Follow [querying](../skills/graphify/references/querying.md). Start with a small budget and identifiers from the actual project.
6. Verify important relationships against current sources; disclose unsupported/skipped files.
7. Answer the original question. Save a selected verified discovery through [work memory](../skills/graphify/references/work-memory.md) only when useful and approved.

Success means a sourced answer with scope/limitations, not merely an output graph. No agents, hooks, guards, HTTP services or production changes are part of this workflow.
